# KubeJS Thaumaturge

This addon connects [Thaumaturge](https://github.com/Leclowndu93150/Thaumaturge) to KubeJS. If you can write a KubeJS script, you can add jars, wand parts, golem materials, recipes, aspects and research to Thaumaturge.

There is one build of the addon per Minecraft version, and each has its own guide. Pick yours:

| | Minecraft 26.1.2 | Minecraft 1.21.1 |
|---|---|---|
| Guide | [26.1.2 docs](26.1.2/) | [1.21.1 docs](1.21.1/) |
| KubeJS | 8.0.6 or newer | 2101.7.2 or newer |
| Thaumaturge | 0.2.1 or newer | 0.4.6 or newer |

Both are NeoForge. Not sure which you have? It is the Minecraft version on your launcher profile.
